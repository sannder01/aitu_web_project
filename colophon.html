About this website

This website consists of ordinary HTML files. Anuar and I wrote it in Visual Studio Code, and we found the process very interesting. You do not need a separate server to open this website; you can open it directly from its folder.

How a page works

The browser reads the markup and builds the DOM, a tree of elements. You will see headings, paragraphs, lists, and form fields with the browser's default styling. For example, the <h1> element represents the page's main heading. The usual keyboard shortcut for saving a file in an editor is Ctrl + S.

<main>
    <h1>Workouts</h1>
    <p>Information about the gym.</p>
</main>

An editor message might look like this: File saved. This is an example message, not the result of checking this website. A colophon is a section containing information about how a work was created.

Sources and form

The name, addresses, and offer conditions come from public sources. The main source is the official Underground Gym website. The link text Trial workout refers to a practice questionnaire. It checks required fields but does not book a visitor into the club. After validation, the browser opens the form file again.
