О создании сайта

Этот сайт состоит из обычных файлов HTML. Мы с ануаром писали его в таком редакторе как visual studio code, сам процесс написания нам был очень интересен. Для открытия данного сайта вам не нужен отдельный сервер мы можете открыть его через папку

Как устроена страница

Браузер читает разметку и строит DOM - дерево элементов. Вы увидите заголовки, абзацы, списки и поля формы, оформление остается стандартным. Например элемент <h1> обозначает основной заголовок страницы. Для сохранения файла в редакторе обычно используется Ctrl + S.

<main>
    <h1>Тренировки</h1>
    <p>Информация о зале.</p>
</main>

Сообщение редактора может выглядеть так: Файл сохранен. Это пример сообщения, а не результат проверки данного сайта. Colophon - раздел со сведениями о создании работы.

Название, адреса и условия предложений взяты из открытых источников. Основной источник - официальный сайт Underground Gym. Название ссылки Пробная тренировка указывает на учебную анкету. Она проверяет обязательные поля, но не записывает посетителя в клуб. После проверки браузер открывает файл формы повторно.
