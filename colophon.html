О создании сайта

Этот сайт состоит из обычных файлов HTML. Их можно открыть в браузере прямо из папки. Для просмотра не требуется отдельный сервер. В каждой странице есть заголовок, меню, основное содержимое и подвал. Меню использует относительные ссылки: браузер ищет соседний файл в той же папке.

Как устроена страница

Браузер читает разметку и строит DOM - дерево элементов. Затем он показывает заголовки, абзацы, списки и поля формы. Оформление остается стандартным. Например, элемент <h1> обозначает основной заголовок страницы. Для сохранения файла в редакторе обычно используется Ctrl + S.

<main>
    <h1>Тренировки</h1>
    <p>Информация о зале.</p>
</main>

Сообщение редактора может выглядеть так: Файл сохранен. Это пример сообщения, а не результат проверки данного сайта. Colophon - раздел со сведениями о создании работы.

Источники и форма

Название, адреса и условия предложений взяты из открытых источников. Основной источник - официальный сайт Underground Gym. Название ссылки Пробная тренировка указывает на учебную анкету. Она проверяет обязательные поля, но не записывает посетителя в клуб. После проверки браузер открывает файл формы повторно.

Материал подготовлен с помощью AI и требует самостоятельной переработки по правилам задания. Личные фотографии и цитату сотрудника нужно получить при посещении. Окончательный командный сайт должен содержать шесть страниц и общее меню. После объединения файлов необходимо повторно проверить ссылки и номера строк в списке тегов.
